# Ivano

A small German-language HTML/CSS project about the Croatian national football team.

[Open the website](https://openmind-it-gmbh.github.io/ivano/)

## Local preview

Open `index.html` in a browser. No dependencies or build step are required.

## Deployment

GitHub Pages publishes the root of the `main` branch. Push changes to `main` to update the website. The `.nojekyll` file keeps the site as plain static HTML/CSS.

Images and the Google Font load from external services, as in the original project.
